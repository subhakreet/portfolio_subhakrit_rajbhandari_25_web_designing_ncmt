# Subhakrit Rajbhandari — Portfolio

My personal portfolio website. Built with plain HTML, CSS and JavaScript — no
frameworks and no build step. Open `index.html` directly or serve the folder.

**Live:** https://subhakrit.com.np

## How it works

- `index.html` — page markup and inline SVG icon sprite
- `assets/css/style.css` — all styling
- `assets/js/main.js` — interactions and rendering
- `data/` — page content (profile, skills, experience, education, certifications,
  achievements) stored as JSON and loaded into the page on start
- `assets/images/profile/avatar.svg` — profile picture
- `CNAME` — custom domain for GitHub Pages

Fonts (Manrope and Geist Mono) are loaded from Google Fonts.
