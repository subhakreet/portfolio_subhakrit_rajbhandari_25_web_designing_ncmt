# Color Palette

Premium dark cybersecurity theme — charcoal base, soft blue/cyan accents, subtle neutrals.

## Brand — Surfaces

| Token | Hex | Usage |
| --- | --- | --- |
| `ink-950` | `#06090d` | Deepest background / footer |
| `ink-900` | `#0b0f14` | Primary page background |
| `ink-850` | `#0e141c` | Card surfaces |
| `ink-800` | `#111827` | Elevated panels |
| `ink-700` | `#1a2432` | Borders / dividers (strong) |
| `ink-600` | `#263247` | Scrollbar thumb / borders |

## Brand — Accent (soft blue → cyan)

| Token | Hex | Usage |
| --- | --- | --- |
| `accent-300` | `#7dd3fc` | Highlight text on accent |
| `accent-400` | `#38bdf8` | Primary accent, icons, tags |
| `accent-500` | `#0ea5e9` | Buttons, links, progress |
| `accent-600` | `#0284c7` | Gradient end, hover |
| `glow` | `#22d3ee` | Cyan glow, gradients |

## Neutrals (text)

| Token | Hex | Usage |
| --- | --- | --- |
| `slate-50` | `#f8fafc` | Headings (highest emphasis) |
| `slate-100` | `#f1f5f9` | Primary text |
| `slate-300` | `#cbd5e1` | Secondary text |
| `slate-400` | `#94a3b8` | Muted body text |
| `slate-500` | `#64748b` | Low-emphasis / captions |

## Semantic

| Color | Hex | Usage |
| --- | --- | --- |
| Success | `#34d399` | Availability dot, form success |
| Danger | `#f87171` | Reserved for errors |

## Gradients

- **Text gradient:** `#7dd3fc → #38bdf8 → #3b82f6` (`text-gradient`)
- **Button gradient:** `#0ea5e9 → #0284c7`
- **Progress bars:** `#0284c7 → #38bdf8 → #22d3ee`
- **Grid lines:** `rgba(125,211,252,0.06)` on `#0b0f14`
