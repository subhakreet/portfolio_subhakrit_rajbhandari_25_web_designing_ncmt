# Wireframes

Low-fidelity, block-level layout of the home page.

```
+--------------------------------------------------------------+
| Navbar: [logo]  About Exp Expertise Proj Skills Contact [Resume] |
+--------------------------------------------------------------+
| HERO  (full viewport)                                        |
|   Left: status · Name · Headline · Intro · CTAs · Stats 2x4   |
|   Right: profile photo card + floating badges                 |
+--------------------------------------------------------------+
| ABOUT  (2-col)  bio + highlight cards  |  profile snapshot    |
+--------------------------------------------------------------+
| EDUCATION  (2-col)  degree card       |  areas of study       |
+--------------------------------------------------------------+
| EXPERIENCE (timeline) roles + highlights + responsibility chips|
+--------------------------------------------------------------+
| EXPERTISE  (4-col grid) 8 capability cards                    |
+--------------------------------------------------------------+
| PROJECTS / HIGHLIGHTS (2-col) engagements + hall of fame      |
+--------------------------------------------------------------+
| SKILLS  (4-col) categorized skill bars                        |
+--------------------------------------------------------------+
| CERTIFICATIONS (2-col) recognition cards                      |
+--------------------------------------------------------------+
| CONTACT  (2-col) channels     |  form (name/email/subject/msg)|
+--------------------------------------------------------------+
| FOOTER  tagline · socials · copyright · back-to-top           |
+--------------------------------------------------------------+

Global overlays: scroll progress bar · custom cursor · particles/grid bg
```

The detailed mid-fidelity layout is in `../mockups/home-page.html`.
