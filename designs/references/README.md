# References

Design references used to shape the aesthetic:

- Modern senior-engineer / security-researcher portfolios (minimal, premium, high whitespace)
- Dark premium product landing pages (soft blue/cyan accent on charcoal)
- Framer Motion / Tailwind UI patterns for scroll reveals and micro-interactions

## Principles kept in mind

- Subtle cyber details only — no Matrix rain, glitch spam, or skull motifs
- Premium typography, generous spacing, thin borders, soft shadows
- Glassmorphism used sparingly (navbar, floating socials, badges)
- Every animation must enhance, never distract
